# Starbucks Beverage Analytics Dashboard

## Project Overview

This Power BI dashboard analyzes Starbucks beverage data to understand
calorie content, sugar levels, caffeine levels, and beverage
distribution across categories.

## Tools Used

-   Power BI
-   Excel / CSV Dataset
-   DAX
-   Data Visualization

## KPIs

-   Total Beverages: 33
-   Average Sugar: 33.02 g
-   Average Calories: 194.30 kcal
-   Average Caffeine: 81 mg

## Dashboard Features

-   Protein range filter
-   Beverage preparation filter
-   Global Starbucks presence map
-   Beverage category distribution
-   Caffeine and calorie comparison charts
-   Top caffeine beverages analysis
